## 4. Metrics — explicit numerators, denominators and edge cases
Population: all preregistered eligible races, not only successful predictions. Log attempted/success/error/late/held/no-record races, target roster, known status at cutoff, official actual starters and result coverage, unmatched IDs and cancellations. Primary grade performance denominator is official starters with valid locked grades and verified final result; grade coverage also report all declared eligible non-cancelled-at-cutoff runners separately, plus starter coverage. Do not retroactively erase prestart UNKNOWN or change grade for later withdrawal. Official cancelled/excluded/nonstarters not in win/top3 denominators; report counts/status separately. Official DNF/disqualified starter remains denominator as not win/top3 unless official final classification says otherwise. Dead heat: official finish=1 or <=3 inclusive (can be multiple); race winner capture any official winner and report all-winner capture separately. No contest/void/unavailable result excluded from result metrics with counts/reasons, not from attempted coverage. Missing prediction is NOT UNASSESSED; report failure separately. Explicit UNASSESSED is a valid abstention, not C.
