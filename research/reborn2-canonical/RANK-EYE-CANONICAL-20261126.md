# BAKEN LAB REBORN 2｜1レースの予想工程・RANKとLAB EYE
原典：2026-11-26 JST ユーザーが再提示した過去メッセージ。提示された範囲を固定する。

## 1レースの予想工程
公式データ取得（全出走馬・過去走・対戦相手・競走条件）→ 7大分類・100項目分析（全出走馬を同一基準で分析）→ RANK / LAB EYE → 最終整合性監査 → FROZEN。

## RANK ― 全頭総合評価
今回のレースで、本当に強い馬はどの馬なのか。
100項目の分析材料から、馬自身の能力だけでなく、今回の条件で発揮できる能力まで評価する。
基礎能力・過去走内容・相手関係・今回の適性・展開と隊列・好走再現性。オッズ完全不使用。

| RANK | 名称 | 定義 |
|---|---|---|
| S | 最有力馬 | 勝ち切る能力と今回条件に強い裏付けがある。 |
| A | 有力馬 | 今回のレースで十分に勝ち負けできる。 |
| B | 好走候補 | 条件や展開次第で上位に入る可能性がある。 |
| C | 評価劣勢 | 今回の条件では他馬より評価を下げる根拠がある。 |

100点方式・順位付け・固定TOP5は廃止。各ランクの頭数に制限を設けず、S評価がいないレースも認める。データ不足はCではなく未評価として区別する。

## LAB EYE ― 穴馬発掘専用分析
一般的な予想では見落とされやすい、今回の好走理由はないか。
RANKとは異なる視点で、全出走馬を再検査する。

| No. | 専用発掘項目 |
|---|---|
| 01 | 着順と着差のギャップ |
| 02 | 着順と過去走内容のギャップ |
| 03 | 道中後退からの巻き返し |
| 04 | 強い相手との僅差敗戦 |
| 05 | 対戦相手の後続実績 |
| 06 | 前走の展開不利の解消 |
| 07 | 得意距離・条件への復帰 |
| 08 | コース変更による適性向上 |
| 09 | 先行馬占有率による恩恵 |
| 10 | 逃げハサミによる恩恵 |
| 11 | 同型馬の減少 |
| 12 | 想定隊列による位置取り改善 |
| 13 | 着順に表れていない能力上昇 |
| 14 | 転入・クラス変更による相手弱化 |
| 15 | 複数の条件好転の組み合わせ |

発掘根拠の監査 → 単勝10倍以上（確定時オッズで判定）。

## 最終整合性監査
EYEで発見した能力材料も総合評価に反映。根拠の重複・評価矛盾・欠損を確認。

## FROZEN
RANK・LAB EYE確定保存。
