## 一元化した実行経路

`run.mjs` → `validateInput` → `evaluateRace` → `compareCohort`。

1. **取得・検証**: オフラインの固定入力を受け入れる。馬ID・馬名・ACTIVE集合、公式参照先、取得時刻、入力固定時刻、SHA-256、過去競走IDを検査。取消・非出走イベント・障害・未来走・対象レースの走歴は採用しない。最新DBへの読み足しはしない。
2. **判定**: 同一データから各馬の全条件を計算。相対先行順位は全ACTIVE集合からdense rankで計算し、TOP5外だけを母集団にしない。欠損はMISSING/UNCONNECTED、未取得をfalse/0点にしない。
3. **独立100点採点**: 発走前に固定した項目配分（合計100）と、馬ごとの実際の項目別評価・根拠を要求。既定の配点は作っていない。各馬の点数は他馬の採点を変更しても変わらない。人気・オッズは入力時点で拒否する。S〜Fは実評価を要求し、順位から生成しない。
4. **重複防止**: URLや研究名ではなく `馬ID/競走日/競馬場/R` を根拠依存単位とする。同じ実走を距離・同場・Eval等に言い換えて二重加点しない。最初に使う項目の優先順は事前固定した採点表で定め、結果を見て選ばない。抑止した点数・重複相手も記録する。
5. **順位・TOP5**: 全ACTIVE馬の採点完了後だけ確定。同点は発走前の基準順位があれば維持し、なければ未解決として停止。根拠なしの馬番順を能力順位にしない。
6. **EYE**: TOP5外全頭の個別監査、否定材料・欠損、全組比較、独立肯定因子2件以上を要求。同じ競走の根拠に依存した因子は重複扱い。選出は最大1頭・null可。既存EYEは維持するが、再監査していないものを完了済みとしない。芝1800m以下の補完だけを実装し、ダート・長距離の新補完はしない。
7. **比較**: 推論を完成させた後だけ別ファイルの公式確定結果を読み込む。TOP5＋EYEの3着以内馬を重複なく数える。馬単位の新規/喪失と、レース単位の的中維持を分離する。EYE監査未完了のレースは完全成績比較に含めない。

※同じ実走を一依存単位とする重複抑止は、保守的な研究設計であり、本番監査規則を変更したものではない。真に独立した観察まで抑止しないか、原本を用いた検証が必要。

### 来歴の限界

SHA-256は文書と評価値の改変検出であり、その文書が本当にその日時に存在したことを単独で証明しない。`verified`や時刻を自動trueにする処理はない。実比較では、主張を裏付けるimmutable保存記録・公式取得証拠との照合が別途必要。自由文の独立性・因果推論の正しさも、形式検証だけで証明したとは扱わない。
