## 同じ候補集合での交差比較

物理的な出走集合623頭は維持し、相対先行dense順位を46頭除外後に再計算しない。候補だけ共通577頭に制限する。

|共通577頭|旧EYE方式|V7 EYE方式・証拠一式|
|---|---:|---:|
|旧順位|87|85|
|V7仮順位|77|83|

全体の順次差分は **92 → 85 → 87 → 77 → 83**。

- 46頭を直接除去すると捕捉7頭消失（92→85）。TOP5を補充しないこの条件だけでは10RでTOP5が不足する。
- 共通候補で旧方式を再実行すると補充によって2頭回復（85→87）。候補変更の純差は−5。
- 旧EYEを固定して順位を置換すると−10（87→77）。続けてEYEを置換すると+6（77→83）。
- 逆順ではEYE置換−2（87→85）、順位置換−2（85→83）。交互作用は+8。

**置換順に依存する条件付き差分であり、純粋な因果寄与ではない。** 順位置換には入力特徴・採点法の差も含まれ、EYE置換には証拠と選出方針の差も含まれる。8頭分を特定原因の8頭と解釈しない。旧点数とV7支持点を減算して能力変化と解釈しない。

全頭支持あり21Rは46→44、46頭の一部を含む25Rは46→39。21Rだけを良い比較対象として選別せず、双方を報告する。

## 同一入力で比較できる範囲と限界

623頭全てでRAW取得は発走前。ただし元FROZEN以前の取得は18頭。採用履歴の取得時計は577頭で元FROZEN以前を検査できるが、これは元のモデル入力の完全一致を証明しない。観測履歴の同一窓は39頭、全頭同一窓のレースは0R。共通の履歴原子は1,309件。RAW未採用1,153件、V7採用側の非同一履歴259件がある。

従って、**元評価まで含む同一入力を厳密に証明できるレースは0R**。今回実行できたのは固定済み出力・共通候補による交差比較である。全数の取得時計・照合結果は `analysis/sources623.csv` / JSONを参照。

## 消失30頭・新規21頭

馬別一覧は [horse-comparison.md](horse-comparison.md)、詳細は `reports/LOST30/` と `reports/NEW21/`。全頭の六条件の選出、共通順位、境界馬との差15軸、共有配分前後、未知項目、EYE監査、採用履歴、追い越した相手を保存した。

消失30頭は評価外7頭と採点支持あり23頭。支持あり23頭は全て共通候補で順位低下。条件付き分類は順位変更感応20頭、EYE方式変更感応2頭、両変更時のみ消失1頭、評価外7頭。EYE不成立は独立2機序不足11頭、同一レース根拠の独立性未証明10頭、別候補優先2頭、評価外7頭。

新規21頭はV7 TOP5経由17頭、EYE経由4頭。共通候補順位は上昇18頭、同順位2頭、下降1頭。従って新規捕捉を全て「採点が押し上げた」とは言えない。条件付き分類は順位感応13頭、EYE感応4頭、どちらの置換でも捕捉2頭、候補補充2頭。

境界分析の値はV7内での点差分解であり、旧方式からの変化の一意な原因ではない。未知項目の幅があるので、仮順位を正式順位として扱わない。

## 改善候補の優先順位

1. 元FROZEN入力原文・入力ハッシュ・旧評価器版・完全根拠を回収し、同一入力の対比較を可能にする。回収不能な過去分は厳密比較不能のまま残す。
2. 46頭全頭を公平に公式証跡で再照合する。今回消失した7頭だけを結果から選んで復帰させない。既存採用条件は緩めない。
3. 未知予算とTOP5境界を含む正式順位契約を承認する。未接続6点や欠損を平均値で埋めず、支持点順位を能力確定順位と呼ばない。
4. TOP5とEYEを共同で事前登録する。既存EYE維持・空席補完と全面再選出の仮説は将来比較対象とし、今回の捕捉数で採用方式を決めない。
5. 未知の将来開催を固定入力で対比較する。既知46Rは開発集合として隔離する。

## 将来検証・正式順位の事前登録

発走前に同一のrace/全ACTIVE馬ID/状態/入力原文/取得時刻/ハッシュ/公式証跡を固定し、結果・人気・オッズを別領域に隔離する。評価器版、配点、共有原子予算、同率規則、履歴採用規則、候補集合、欠損処理、EYE独立性・現在性・比較規則、保存期限を結果を見る前に登録する。

正式順位は承認済み評価式・全ACTIVE馬の同一性と採用証跡・未知項目による順位反転可能性を検査した順位と定義する。支持点だけの整列は研究仮順位、情報不足と接戦は別理由として残す。現状のV7/V8で正式順位を新たに確定したレースは0R。

将来比較では同じ入力ハッシュと同じ候補集合の両方式を並行評価し、TOP5捕捉、EYE選出数/1着/3着内率、馬単位の新規捕捉・消失、順位不確定、欠損、失敗・期限切れも全数記録する。対象期間と除外規則を先に固定し、結果に合わせて変更しない。本番保存には別途承認済みプロトコルと正規ゲートが必要。この研究は本番接続しない。
