# V4 敗因診断（採点本体・係数を変更しない）

固定対象: PR51 commit `0a420bd3c2902b2f9bad000c3c0a48ced924aeaf` の V4 type-repaired（46R/623頭、捕捉78）。対照は同じ馬別保存データの先行力強化版92。消失32・新規18頭の50頭を全頭分析する。

## 介入の定義

1. 15配点軸を一つずつ外す。各軸について、(A)保存済み実加点だけを引く固定寄与試験、(B)その軸を外して**既存**allocateで再計算する構造試験を両方実施。残りの係数/上限は一切変更しない。欠損補完・残軸への再配分なし。
2. Evalはコース10点全部ではなく、Evalの2点componentだけを外す。401頭の取得日前不適用は維持する。
3. ラップは展開/持続proxyの2軸をまとめた試験も行う。EYEの位置取り進出はラップを直接使わないため、この試験では消さない。
4. みねた固有と共通信号を区別。固有に追跡できるfrontShare→展開ルート、先行平均/距離/斤量など共通信号を含むルートを別に試す。共通信号全体を「みねたの純効果」とは呼ばない。
5. 上がり・距離の点数だけを外す場合と、EYE肯定mechanismも外す場合を分離。EYEだけの3mechanism除去も行う。全頭レビューは固定済み候補証拠から既存規則どおり再計算する。
6. 重複ガード/共有実走25点上限/0点時のatom予約/処理順の感度を**診断専用**に検査する。これは安全性検証を外した新しい予想候補ではない。独立性が未確認の点数を正当な加点と扱わず、本体・保存ゲートには適用しない。

全ケースを先に列挙し、好成績ケースだけを選ばない。シナリオ出力を固定してからラベルを照合する。ただし既知46Rでの事後診断であり、独立holdout/因果効果/将来改善の証明ではない。
