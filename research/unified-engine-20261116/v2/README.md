- T01: 確認できた直近平地実走の**全通過順位の最小値**。FRONT/SEMI/MID/REARと、道中進出・終盤進出を別記。複数走の生順位平均、旧研究の頭数正規化平均とは別物。
- T02: ACTIVE全頭の先行割合と未知数、下限/上限。厳密な<30%と不確実性を分ける。<40%/>50%は例示で、自動採点条件にしない。
- T03: 馬番n-1/n+1の**文字どおりの隣馬**。取消・欠番を次のACTIVE馬で埋めない。
- T04: 隣接先行馬、枠・最初のコーナーまでの距離・スタート馬場・再現性を分ける。内外の無条件加点なし。
- T05: 発走前に取得済み・学習期間終了済みの複勝ROI、n>=50、10年を要求。<=70→>=90と<60→>=90を区別。自己研究の複勝率1049セルは別proxyで、ROIへの代用なし。
- T06/07: 距離短縮/延長の事実と、想定位置・スタミナ・終い・再現性の未検証を分離。対象レースの実通過順は受け入れない。
- T08: 表面変更、観測範囲の交互使用、距離との関係を記録。4走だけで初芝/初ダートを断定しない。全履歴の確認は取得元・時刻・履歴bindingが必要。
- T09: 不利・位置・終い・ラップ・相手関係の事実と、敗因/今回の再現経路を分離。記述的な進出だけで原因を確定しない。
- T10は市場分離で無効。T11〜13の非公開AI/指数は再現しない。T14は統合であり別加点なし。

## 点数と二重加点

`ledger.mjs` は原子的な観測値＋mechanism＋共有する過去競走を追跡する。同じ事実/仕組みをEval・みねた・独自研究と言い換えても二重加点しない。序盤位置とcorner[0]も同じ観測として結合する。

異なる観測値が同じ実走に属する場合、共有競走の上限と明示的な依存性監査を要求する。第1版相当の厳格な競走単位抑止とのablationを別記する。同じレースだから自動独立にも、自動抑止にもせず、同じ原子的事実の再使用は拒否する。

`engine.mjs` は事前固定・承認済み・別日holdoutの100点配分だけを受理する。配点と共有競走上限の既定値はない。`rubric-proposal.json` は未承認・配点nullであり、実46Rの再採点は**BLOCKED**。合成テストの配点や上限を実馬へ転用しない。46Rは既に結果を観察した探索用集合で、独立holdoutとは呼ばない。

## 正式研究EYE

`eye.mjs` は全TOP5外の個別監査・否定材料・欠損・全組比較を検査する。今回との対応と具体的な再現経路を記録した2種類以上の独立mechanism、確認済みの異なる観測値が必要。共有競走の依存性も明記する。

先行・芝1800m以下・順位6位という必須ゲートはない。非先行馬、長距離やダートも研究候補として公平に監査する。基準EYEの無条件維持は比較用だけで、未適格なEYEを正式監査済みとして保存しない。最大1頭またはnull。現行の本番選出方式は変更しない。

## 検証方法

```sh
node research/unified-engine-20261116/v2/v2.test.mjs
# 46Rは保存済み5R単位の入力を使用。1回に1組だけ検証する:
node research/unified-engine-20261116/v2/run-batch.mjs 1
```

実データの見えていない情報を合成テストの`verified`で補わない。入力・結果は別に読み込み、選定状態を固定するファイルを書いた後でだけ結果を照合する。配点/実監査が不足すれば、点数・順位・EYEの変動、新規捕捉/喪失は0ではなく未測定。
