The reader is a separate function in the same local process, not an independent custodian. Exclusive creation does not prevent a privileged process modifying/deleting a file; tamper is detected. Test fixture permits known cp932 only, tests do not cover all encodings, malformed structures, duplicate JSON keys, concurrent writes, crash durability/fsync, symlink/path safety, full rights matrix, tie/DNF, historical course intervals, actual roster count/source relation, event chronology beyond target ID and observed time, or public-key trust.
