## Important limitations / next research
The test key is public and known to writer and reader. Separate PID is not independent trust, not separate OS identity or independent external custody. Clock values are fabricated; no official origin, real trusted time or signature. No WORM guarantee. The test detects tampering relative to its known receipt but malicious writer can re-sign; no external trust anchor or latest-version authenticated inventory. Selected v1 can be read even if later version exists; production requires authenticated as-of selection and complete correction inventory, separate latest rights/revocation/deletion registry and tombstones, independently checked at analysis and output, not just embedded old rights. Deletion marker is synthetic and missing-file refusal tested; no actual policy-compliant purge/backup deletion orchestration. Cross-issuer native-ID mapping is rejected by same-issuer scope in this probe, not authenticated; need independently corroborated mapping and validity. Source event and course/class facts are fictional. Strict schema does not establish genuine official source. Ancestor-directory substitution, filesystem races, directory durability, full power-loss recovery, multiprocess access permissions, trusted timestamp, malformed CLI framing, resource limits beyond byte size, nested value domain controls and official HTML parser remain open; do not deploy. No evidence admission under alternative observed-only publication policy. No real storage vendor selected or provisioned.
