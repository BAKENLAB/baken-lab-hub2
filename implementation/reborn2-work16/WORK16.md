固定エンジンはV48。対象競走結果、人気・オッズ、本番変更は使用していない。

## 実装した共通取得境界

`work16-material-acquisition.mjs` に以下を固定した。

1. 115項目の4状態分類と、推定値を公式観測として昇格させない契約。
2. 発走前公式出馬表ゲート。
   - 公式出馬表の同一スナップショットに掲載された全馬を保持する。
   - 各馬を `ACTIVE / CANCELLED / EXCLUDED` のいずれかで固定する。
   - 掲載頭数とACTIVE頭数を別に保存する。
   - 発走後の実発走頭数を発走前分析の必須条件にしない。
   - 発走後取得、UNKNOWN、重複馬番を拒否する。
3. 過去競走行ゲート。
   - `race_id / horse_id / horse_no / horse_name / status / source_ref / observed_at` を必須化した。
   - 正式クラス、出走分類、コース版は資料に存在する場合のみ追加し、不明値を推定しない。
4. 対象競走結果、人気・オッズ、本番書込みを拒否する固定ガード。

## 64項目の接続確認

64項目は「公式に同名の直接測定値が存在する」という意味ではない。既存の公式観測を入力として、V48の既存分析へ供給できる経路を確認した状態である。

主な供給材料は、過去競走行、着順、着差、時計、上がり、通過順、レースラップ、距離、馬場、枠・馬番、斤量、クラス、相手、騎手・調教師、今回名簿である。派生判断には証拠IDを付け、直接測定値と区別する。

今回の実行で64項目すべてを新規に外部取得したわけではない。したがって状態は `ROUTE_AVAILABLE` であり、`ACQUIRED` には昇格させていない。

## 直接測定不能15項目

対象: 07, 08, 10, 11, 15, 23, 24, 25, 55, 56, 68, 71, 72, 73, EYE-06。

通常材料で分析できるのは、通過順の変化、時計・上がり、レースラップ、枠と今回名簿、同条件反復、公式裁決により支持または反証できる範囲である。これは瞬発力、余力、砂被り耐性、馬群耐性、消耗原因などの直接測定ではない。

- 複数の独立観測が一致した場合のみ分析材料にする。
- 単走例、結果だけ、人気・オッズからは補完しない。
- 反証と欠損を保持する。
- 直接測定値、因果、確定的な耐性として保存しない。

## 残存障害と第1工程判定

1. 64項目は取得経路接続であり、対象競走ごとの全公式原本取得完了ではない。
2. 未取得16項目は対象別取得・時点証明が未完了。
3. 過去競走の正式クラス・出走資格・コース版は、各公式資料に列または本文根拠がある場合だけ確定できる。
4. Work13資産はSHA不一致のため正式入力から保留。
5. 発走前 `activeCount` をV48の入力フィールドへ渡す最終統合は、分析エンジン本体を変更せずに接続試験する必要がある。

よって、第1工程は **取得契約・共通境界について合格、全材料取得について未完了**。総合判定は **CONDITIONAL / NOT COMPLETE** とする。

本番DB、FROZEN、HUB、デプロイ、main、V48には変更を加えていない。
