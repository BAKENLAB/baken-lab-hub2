馬券の種類、これでわかる。

「単勝と馬連って何が違う？」から大丈夫。
何頭を当てたいかから考えると、馬券はかなり分かりやすくなります。

迷ったら、まずここだけ
1頭
単勝・複勝　この馬！という1頭から買う
2頭
ワイド・馬連・馬単　2頭の組み合わせで狙う
3頭
3連複・3連単　3頭まで読めた時に狙う
開く
各券種の中で流し・BOX・フォーメーション・マルチまで一緒に解説
TAP / 馬券を選ぶと説明が開きます
単単勝選んだ1頭が1着なら当たり＋
単勝とは？
1頭だけ選び、その馬が1着になれば的中。いちばんシンプルな馬券です。
どんな時に？
「この馬が一番強い」「勝ち切る可能性が高い」と、本命1頭に自信がある時。
例
⑧を単勝で購入 → ⑧が1着なら当たり。2着では外れ。
この券種の買い方
通常
単勝は1頭を選ぶ馬券なので、流し・BOX・フォーメーションは使いません。
複複勝選んだ1頭が上位に入れば当たり＋
複勝とは？
選んだ1頭が決められた着順以内に入れば的中。通常は3着以内ですが、出走頭数によって対象着順が変わる場合があります。
どんな時に？
「勝つかは分からないけど、馬券内には来そう」という馬を狙う時。穴馬を1頭だけ狙う時にも使いやすい。
例
⑧を複勝で購入 → 対象が3着以内なら、⑧が1・2・3着で当たり。
この券種の買い方
通常
複勝も1頭を選ぶ馬券なので、流し・BOX・フォーメーションは使いません。
Wワイド選んだ2頭がどちらも上位なら当たり＋
ワイドとは？
選んだ2頭が両方とも3着以内に入れば的中。着順の順番は問いません。
どんな時に？
「この2頭は来そう。でも1着2着まで決めるのは難しい」という時。本命＋穴馬の組み合わせにも向いています。
初心者におすすめ
ワイドは着順を当てなくてよく、買い方も流し・BOXが分かりやすいのが魅力。さらに、買った組み合わせ次第では1レースで2本・3本と複数的中することもあります。
まず1点なら
③－⑧を購入 → ③が1着、⑧が3着でも当たり。
初心者はこの2つから
流し
軸②、相手④⑥⑧なら ②－④⑥⑧。＝ ②－④ / ②－⑥ / ②－⑧ の3点。
結果が ⑧－⑥－② なら、②－⑥と②－⑧の2本的中。軸②が3着でも大丈夫です。
4頭BOX
②④⑥⑧の4頭BOXなら6点。4頭からできる2頭の組み合わせを全部買います。
結果が ⑧－⑥－② なら、⑧－⑥ / ⑧－② / ⑥－② の3本すべて的中＝総取りになります。
覚え方：ワイドは「3着以内の2頭の組み合わせ」。だから、1～3着に買っている馬が3頭入ると、複数のワイドが同時に当たることがあります。
連馬連1着と2着の2頭を順不同で当てる＋
馬連とは？
1着と2着になる2頭を当てる馬券。どちらが1着でもOKです。
どんな時に？
「この2頭が抜けていそう」「1着2着はこの2頭だと思うけど、順番までは分からない」時。
例
③－⑧を購入 → ③→⑧でも⑧→③でも当たり。
初心者はこの2つから
流し
軸⑧、相手③⑤⑩なら ⑧－③⑤⑩。＝⑧－③ / ⑧－⑤ / ⑧－⑩。
BOX
③⑤⑧⑩の4頭BOXなら6通り。4頭のうちどの2頭が1・2着でも、その組み合わせを買えていれば的中。
→馬単1着と2着を順番通り当てる＋
馬単とは？
1着と2着を順番まで当てる馬券です。馬連より条件が厳しい。
どんな時に？
「⑧が勝つ。その相手は③」と、勝ち馬までかなり読めている時。
例
⑧→③を購入 → 1着⑧・2着③なら当たり。③→⑧だと外れ。
この券種で使える買い方
1着流し
1着⑧、相手③⑤⑩なら ⑧→③⑤⑩。⑧が1着で、相手のどれかが2着なら的中。
2着流し
2着⑧、相手③⑤⑩なら ③⑤⑩→⑧。⑧が2着に来る前提です。
BOX
③⑤⑧の3頭BOXなら、順番違いも含めた6通りを買います。
フォーメーション
1着：⑧⑩ / 2着：③⑤⑧ のように、1着候補と2着候補を分ける買い方です。
マルチ
⑧から③⑤⑩へ流す時にマルチを付けると、⑧→相手だけでなく相手→⑧もまとめて買います。
枠枠連1着2着の「枠」の組み合わせを当てる＋
枠連とは？
馬そのものではなく、1着と2着の馬が入っている枠番号の組み合わせを当てます。順番は問いません。
どんな時に？
同じ枠に気になる馬が複数いる時や、枠単位で狙いたい時。発売されているレースで利用できます。
例
3枠－6枠を購入 → 1着と2着が3枠・6枠の馬なら当たり。
初心者はこの2つから
流し
軸3枠、相手1・4・6枠なら 3－1・4・6 の形で広げます。
BOX
選んだ複数の枠からできる組み合わせをまとめて購入します。
3複3連複3着以内の3頭を順不同で当てる＋
3連複とは？
1～3着に入る3頭を当てます。3頭の着順は問いません。
どんな時に？
「この3頭は強そう」「軸1頭は決まったけど、相手を何頭か広げたい」時。順番まで読む必要がないのが特徴。
例
③－⑧－⑩を購入 → ⑩→③→⑧でも⑧→⑩→③でも、3頭が1～3着なら当たり。
この券種で使える買い方
1頭軸流し
軸⑧、相手③⑤⑥⑩なら ⑧－③⑤⑥⑩。⑧＋相手4頭のうち2頭が3着以内に入れば、その組み合わせが的中。
2頭軸流し
軸⑧⑥、相手③⑤⑩なら ⑧－⑥－③⑤⑩。⑧と⑥の両方が3着以内＋相手から1頭で的中。
BOX
③⑤⑧⑩の4頭BOXなら4通り。その4頭のうち3頭が1～3着を占めれば順番不問で的中。
フォーメーション
例：
1頭目：⑧
2頭目：③⑤⑥
3頭目：③⑤⑥⑩

この3つの列から成立する3頭の組み合わせを買います。
ここ重要：3連複の「1頭目・2頭目・3頭目」は着順ではありません。たとえば⑥が2頭目の列にいて、実際に⑥が2着でも3着でも、選ばれた3頭が1～3着に入れば当たる可能性があります。

外れる例：この形では1頭目が⑧だけなので、⑧はどの買い目にも必ず入ります。結果が ⑥－⑤－⑩ のように⑧が3着以内から抜けたら、相手3頭で決まっても「相手決着」で全て不的中です。
3単3連単1～3着を順番通りすべて当てる＋
3連単とは？
1着・2着・3着を順番まで全部当てる馬券。難しい分、配当が大きくなりやすいタイプです。
どんな時に？
勝ち馬だけでなく、2着・3着まで展開をかなり具体的に読める時。点数が増えやすいので買いすぎには注意。
例
⑧→③→⑩を購入 → 着順がそのまま⑧・③・⑩なら当たり。順番が1つでも違えば外れ。
この券種で使える買い方
1着流し
1着⑧、相手③⑤⑥⑩なら、⑧を1着固定して相手から2・3着の並びを作ります。
2頭軸流し
1着⑧・2着③を固定し、3着を⑤⑥⑩へ流すなら ⑧→③→⑤⑥⑩。
BOX
③⑤⑧⑩の4頭BOXなら24通り。4頭から3頭を選び、さらにその着順違いまで全部買います。
フォーメーション
例：
1着：⑧
2着：③⑤
3着：③⑤⑥⑩

なら、各着順欄に入れた馬だけで成立する並びを買います。
3連複との違い：3連単は列がそのまま着順です。たとえば⑥を3着欄にしか入れていないのに実際は⑥が2着に来たら、その買い目は外れます。
1頭軸マルチ
軸⑧、相手③⑤⑥なら、⑧が1着・2着・3着になる並びをまとめて購入。軸の着順を固定したくない時に使います。
2頭軸マルチ
軸⑧・⑥、相手③⑤⑩なら、⑧と⑥がどちらも3着以内に入る前提で、2頭の着順を固定せず相手1頭との並びを全部買います。
たとえば相手が③なら、⑧→⑥→③だけでなく、⑥→⑧→③、⑧→③→⑥、③→⑧→⑥など6通り全部。相手3頭なら18点です。軸2頭のどちらかが4着以下なら外れ。
大事：「難しい馬券ほど偉い」わけではありません。自信がある部分だけを買うのが基本。1頭しか自信がなければ単勝・複勝、2頭ならワイドや馬連、3頭まで読めた時に3連系、と考えると分かりやすいです。
